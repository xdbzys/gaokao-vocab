背群英蓝屏修复指南

不删除、不更新 APP，三种方式任选

方式一：直接用网页版 最简单

不用任何工具，手机浏览器直接打开修复版：

打开背群英网页版
1
点击上方按钮打开网页版
2
浏览器菜单（三个点）→「添加到主屏幕」或「创建快捷方式」
3
以后从桌面图标打开，体验与 APP 一致
网页版功能与 APP 完全一致，通过 localStorage 保存学习记录。但与 APP 的学习记录不互通，需重新导入词库。

方式二：持久化修复 APP 推荐

通过注入 Service Worker，让蓝屏的 APP 每次启动都自动加载修复版，一次修复永久生效。

修复后 APP 重启、手机关机重启都依然有效，学习记录保留。

方案 A：电脑 + USB 数据线

1
手机开启 USB 调试：设置 → 关于手机 → 连点 7 次版本号 → 返回 → 开发者选项 → USB 调试
2
电脑下载 Android Platform Tools 并解压
3
数据线连接手机，手机弹窗点「允许 USB 调试」
4
下载修复脚本：
curl -sL https://raw.githubusercontent.com/xdbzys/gaokao-vocab/master/fix_bluescreen_persistent.py -o fix.py
5
在 Platform Tools 目录运行：
python fix.py

方案 B：手机 Termux（无需电脑）免电脑

1
安装 Termux（F-Droid 版，Play 商店版已过期）
2
手机开启无线调试：设置 → 开发者选项 → 无线调试 → 开启
3
在 Termux 中粘贴运行以下命令（一次性全部复制）：
pkg update -y && pkg install -y python android-tools curl && curl -sL https://raw.githubusercontent.com/xdbzys/gaokao-vocab/master/fix_termux.sh -o fix.sh && bash fix.sh
4
按提示输入无线调试地址（在无线调试页面查看）
修复原理说明

蓝屏原因：APP 内置的网页使用了 import.meta 语法，旧版安卓 WebView 不支持，导致 JavaScript 崩溃，页面只显示背景色。

修复原理：通过 ADB 连接 APP 的 WebView 调试接口，注入一个 Service Worker（SW）。这个 SW 拦截 APP 的所有页面加载请求，自动重定向到 GitHub Pages 上的修复版网页。SW 存储在 WebView 数据目录中，APP 重启后依然生效。

恢复方法：设置 → 应用 → 背群英 → 存储 → 清除数据（会清除学习记录）

需要 APP 是 Debug 版本（支持 WebView 调试）。如果是 Release 版本，脚本会提示使用方式一。

方式三：清除缓存（先试试）

有些情况下蓝屏是缓存问题，清除缓存可能直接解决：

1
手机设置 → 应用管理 → 背群英
2
点「存储」→「清除缓存」（不要点清除数据！）
3
重新打开 APP 看是否恢复
如果清除缓存后仍然蓝屏，请使用方式一或方式二。
