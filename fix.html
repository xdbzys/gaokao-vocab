背群英蓝屏修复

选择适合你的修复方式：

方式一：直接用网页版（最简单）

不用 ADB、不用电脑，直接在手机浏览器打开修复版：

打开背群英网页版

打开后点击浏览器菜单 →「添加到主屏幕」，以后从桌面图标打开即可。

学习记录通过 localStorage 保存，与 APP 版数据独立，需要重新导入词库。

方式二：ADB 修复 APP（保留学习记录）

通过 ADB 让蓝屏的 APP 加载修复版网页，学习记录不会丢失。

电脑 + USB 方式

1
手机开启 USB 调试：设置 → 关于手机 → 连点7次版本号 → 返回 → 开发者选项 → USB调试
2
电脑下载 Android Platform Tools 并解压
3
数据线连接手机，手机弹窗点「允许 USB 调试」
4
下载修复脚本 fix_bluescreen.py
5
在 Platform Tools 目录运行：python fix_bluescreen.py

手机 Termux 方式（无需电脑）

1
手机安装 Termux（F-Droid 版）
2
在 Termux 运行：pkg install python android-tools curl git
3
开启无线调试：设置 → 开发者选项 → 无线调试 → 开启
4
在 Termux 运行：adb connect localhost:5555，手机弹窗点允许
5
下载并运行：curl -sL https://raw.githubusercontent.com/xdbzys/gaokao-vocab/master/fix_bluescreen.py -o fix.py && python fix.py
注意：ADB 修复是临时的，APP 被杀进程后需要重新运行脚本。永久修复建议安装新版 APK。

方式三：安装新版 APK（永久修复）

直接安装新版 APK 覆盖旧版，不影响学习记录：

下载新版 APK

下载后直接安装，无需卸载旧版。
